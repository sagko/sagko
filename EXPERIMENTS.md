# SAGIZ / Experiment playbook

A practical framework for turning technical curiosity into useful, reproducible work.

## Start with a concrete problem

Write down the current workflow, its friction, and one measurable improvement. Choose a small enough scope to finish and explain.

## Establish a baseline

Record the starting inputs and output. Use sample or synthetic data. Keep secrets and personal information out of public examples.

## Build the smallest working version

Automate one repeatable step. If using AI, state the model or tool, the task, and how the output is checked by a person or a deterministic check.

## Verify the result

Try a typical input, an empty input, and an invalid input. Record what passed, what failed, and what remains uncertain. Compare the result with the baseline.

## Publish a useful entry

Use this format for each completed experiment:

```text
Title:
Date:
Problem:
Approach:
How to reproduce:
Expected result:
Actual result:
Limitations:
Next improvement:
```
